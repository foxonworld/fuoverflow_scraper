ISSUES FOUND
================================================================================

[1] PRIMARY BUG: AUDIT ANSWER FEATURE NOT WORKING
    
    Location: app/routes.py - Lines 492-515 and 528-545
    Endpoints:
    - POST /api/audit/subjects/{name}/apply
    - POST /api/audit/subjects/{name}/smart/apply
    
    Root Cause:
    The endpoints received the changes parameter but didn't validate or 
    extract the answer values properly. When the frontend sent full audit 
    result objects (not just answer strings), the code assigned entire 
    dictionaries as answer values.
    
    Example Bug:
    
    Input:  changes = {"q1": {"old_ans": "A", "suggested": "C", "stats": {...}}}
    Result: question.ans = {"old_ans": "A", "suggested": "C", ...}  ← WRONG!
    
    Expected: question.ans = "C"  ← CORRECT!
    
    Impact:
    - Quiz data becomes corrupted
    - Answers are dictionaries instead of strings
    - AI features fail when processing
    - Audit feature completely broken

================================================================================
BUGS FIXED (2 ENDPOINTS)
================================================================================

[FIX #1] POST /api/audit/subjects/{name}/apply

OLD CODE (Buggy):
    for q_id, new_ans in changes.items():
        if q_id in id_map:
            id_map[q_id]["ans"] = new_ans  ← Assigns ANY value
            id_map[q_id]["is_audited"] = True
            updated += 1

NEW CODE (Fixed):
    for q_id, new_ans in changes.items():
        if q_id in id_map:
            # Extract answer value: handle both string and dict formats
            ans_value = new_ans
            if isinstance(new_ans, dict):
                ans_value = new_ans.get("suggested", "?")  ← Extract suggested
            if isinstance(ans_value, str) and ans_value.strip():  ← Validate
                id_map[q_id]["ans"] = ans_value.strip()  ← Safe assignment
                id_map[q_id]["is_audited"] = True
                updated += 1


[FIX #2] POST /api/audit/subjects/{name}/smart/apply

OLD CODE (Buggy):
    for q_id, ans in changes.items():
        if q_id in id_map:
            id_map[q_id]["ans"] = ans  ← Assigns ANY value
            id_map[q_id]["is_smart_audited"] = True
            updated += 1

NEW CODE (Fixed):
    for q_id, ans in changes.items():
        if q_id in id_map:
            # Extract answer value: handle both string and dict formats
            ans_value = ans
            if isinstance(ans, dict):
                ans_value = ans.get("final_ans", "?")  ← Extract final_ans
            if isinstance(ans_value, str) and ans_value.strip():  ← Validate
                id_map[q_id]["ans"] = ans_value.strip()  ← Safe assignment
                id_map[q_id]["is_smart_audited"] = True
                updated += 1
